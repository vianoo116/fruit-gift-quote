# 场景规则表（来自经营者访谈，v1.1）

## 总原则

1. **礼盒优先推荐整箱原包装礼盒**（inventory.csv 中 type=整箱礼盒）。
2. **组装礼盒一般不推荐**：只有顾客明确要求"组装 / 混装 / 自己搭配几样"时才提供；即使提供，也要先给出 1–2 款可以代替的整箱礼盒，并说明原因（原包装更新鲜、更体面、不易磕碰）。
3. **榴莲按个零售，不属于礼盒范围**：顾客要买榴莲时，说明榴莲单个购买，不放进礼盒，可以另外单独报价。
4. 三档方案 = 三款不同价位的整箱礼盒（或同一款的不同规格）；每档只放一款整箱礼盒为主，必要时可以"一款主礼盒 + 一款小礼盒"。

## 场景规则

| 场景 | 档次倾向 | 价值 | 包装风格 | 忌讳 / 偏好 |
| --- | --- | --- | --- | --- |
| 拜访领导、求人办事、商务送礼 | 高档优先 | 高，看起来要贵重 | 大气 | 进口、精品优先（如车厘子、佳沛金果、蓝莓）；不推荐普通档 |
| 探病 | 普通 | 一般、实惠即可 | 实在 | 不送梨；优先寓意平安（苹果、柚子） |
| 婚庆伴手礼 / 回礼 | 普通 | 性价比高 | 精美好看 | 不送梨；份数多，优先伴手礼小盒；寓意吉利、甜蜜、早生贵子 |
| 公司福利 | 普通至精品 | 性价比高 | 实在或大气 | 选大众都能接受的；量大时注意库存 |
| 春节走亲、节日送礼 | 精品 | 中等 | 大气 | 吉利寓意（橙、橘、柚、苹果） |
| 祝寿 | 精品至高档 | 中高 | 大气 | 寓意平安、长寿 |
| 开业 | 精品 | 中等 | 大气 | 旺来（凤梨）、心想事成（橙） |
| 乔迁 | 普通至精品 | 中等 | 实在 | 不送梨；寓意平安 |
| 未说明 | 按预算 | — | — | 先按预算给三档，并提示询问用途 |

## 包装偏好

顾客说"大气、有面子、上档次"→ 优先 packaging_style=大气；说"实在、量多、划算"→ 优先 实在；说"好看、精致"→ 优先 精美。

## 暂不做（写进迭代计划）

- 多位顾客同时下单时的库存占用，以及库存不够时向隔壁档口借调。
- "同场景其他顾客常选"推荐（不显示价格和顾客信息）：需要真实成交记录，等 P2 记录成交数据后再做。
